# 2026-08-11

## nekosearch 项目初始化（已完成）
- 用 Rust 搭建对标 Google 的自建搜索服务器骨架；已创建公开仓库 https://github.com/neko233-com/nekosearch （`main` 分支已推送）。
- 架构：单二进制 `nekosearch`，`--role all` 默认单机全角色；集群可拆 `registry`/`crawler`/`indexer`/`searcher` 独立进程。
- 注册中心：内置零外部依赖的 `Registry` trait，`InMemoryRegistry`(进程内) + `HttpRegistryClient`(集群) 两种实现，统一管理爬虫执行器（注册/心跳/任务派发），支持水平扩容。
- 索引：`InMemoryIndexer`（进程内倒排索引，简化 TF-IDF），`Indexer` trait 同样有内存/HTTP 两套实现。
- 爬虫执行器：`CrawlerExecutor` trait + http/fs 两个示例，BFS 外链回灌。
- 部署：Dockerfile（多阶段）+ docker-compose.yml（单机 all）+ deploy.sh（自动 docker/cargo）+ .env.example（clap env 注入）。
- 文档：AGENTS.md（开发规范，约定测试/CI 只保留单机 `--role all` 基线）、PLAN.md（架构与路线图）。
- 约束落地：“测试必须只保留一个” => 仓库测试矩阵仅以单机全角色为唯一基线。
- 注意：沙箱环境无 Rust 工具链，代码按可编译标准编写但**未执行 `cargo build`**，需在本机验证。
