## 真实验证：本机装 Rust 跑 `cargo check`

- 沙箱无 Rust 工具链；放开沙箱后 `rustup` 装到 `C:\Users\14170\.cargo`（cargo 1.96/1.97）。
- `cargo check --workspace` 抓到多个仅靠肉眼发现不了的编译错误，全部修掉：
  1. jieba-rs 0.10 `cut` 返回 `Vec<Token>` 而非 `Vec<&str>` → `tokenize` 改用 `raw.word`（`crates/core/src/indexer.rs`）。
  2. clap 4 把 `env` 拆成独立 feature → `node/Cargo.toml` 加 `features=["derive","env"]`。
  3. `registry::PingResp` 仅 derive `Serialize` 缺 `Deserialize` → HA 心跳 `/ping` 解析失败；已补。
  4. `SledIndexer`/`InMemoryIndexer` 的 `add` 无条件 `doc_count++` → 演示数据每次重启重跑导致计数膨胀、BM25 的 `n` 失真；改为仅新文档 `+1`。
  5. `ShardedIndexer::suggest` 的 `.query` 数组元素类型不一致（`&str` vs `&String`）→ 统一 `&str`。
  6. 清理未使用导入 `NodeInfo`、未使用 `Result`、trait 死代码 `name` 告警。
- 最终 `cargo check --workspace` 全通过、零 warning（CHECK_EXIT=0）。已纳入 `Cargo.lock`。

## 约束（重要）

- 本沙箱**无法链接出可执行文件**：无 MSVC 链接器（`cl.exe` 缺失）、无 MinGW（`gcc`/`ld` 缺失）、WSL(docker-desktop) 内也无 cargo/gcc。`cargo check`（不链接）可验证编译，但端到端实跑需本机完整 Rust 工具链：`cargo build --release` + `bash scripts/verify.sh`。
- headless 环境 `git push` 仍 401（凭据子进程取不到 OS 钥匙串 gh token），沿用 `gh auth token` 临时注入 + inline `insteadOf` 推送，令牌未落盘、输出已脱敏。
